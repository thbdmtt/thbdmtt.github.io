# Thibaud Myotte

L’amour du vin. L’artisanat du code.

Page personnelle : vin, hospitalité, développement web et data.

Site : https://thbdmtt.github.io/

## Structure

- index.html : contenu, contacts et métadonnées.
- style.css : mise en page responsive.
- thibaud.png : portrait original, sans fondu ni retouche.
- monogram.svg : icône du site.

Site statique sans dépendance ni étape de compilation. GitHub Pages publie la racine de la branche main. Le fichier .nojekyll désactive le traitement Jekyll.

Les fichiers sont maintenus depuis le projet local Atelier viticole, avec vitrine/scripts/export-personnel-pages.mjs. Les CV, sources privées et notes de travail ne font pas partie de ce dépôt.
